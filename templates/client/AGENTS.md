# Правила клиентского сайта TANEM

- В этом репозитории хранится только `site.json`, папка `assets/` и workflow публикации.
- Не копируй сюда исходный код, компоненты или исправления из старых сайтов.
- За внешний вид и адаптивность отвечает закреплённая версия `tanem-site-engine-v2`.
- Меняй дизайн только в центральном engine и только после проверки трёх эталонов.
- Не выдумывай цены, адреса, расписание, акции, отзывы и ссылки. Неизвестное уточняй.
- Все локальные изображения должны быть в `assets/` и в формате WebP, AVIF или SVG.
- После изменений дождись зелёной GitHub Actions сборки и проверь мобильную версию.
- Не переключай клиента на новую версию engine без отдельной тестовой сборки.
