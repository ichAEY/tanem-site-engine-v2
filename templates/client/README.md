# Клиентский цифровой офис TANEM

Этот репозиторий содержит только данные одного клиента:

- `site.json` — тексты, услуги, цены, контакты и настройки;
- `assets/` — только изображения этого клиента;
- `.github/workflows/pages.yml` — проверка, сборка и публикация.

Разметка и стили загружаются из закреплённой версии `tanem-site-engine-v2`. Поэтому здесь не должно быть HTML, CSS, React/Next.js и клиентских «патчей».

Любое изменение в `main` сначала проходит проверку схемы и лимитов веса. Если данные неверны или фотография слишком тяжёлая, публикация остановится, а работающая версия сайта останется на месте.
