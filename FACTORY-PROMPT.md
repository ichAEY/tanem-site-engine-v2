# Короткий запрос для выпуска сайта

Используйте этот запрос в ChatGPT Work или Codex после того, как шаблон принят:

```text
Создай и опубликуй новый цифровой офис TANEM.

Источник данных: <ссылка на Яндекс Карты или приложенная анкета>
Репозиторий клиента: ichAEY/<repo>
Домен: <name>.tanem.ru
Специализация: <nails / hair / brows / lashes / cosmetology>

Используй закреплённый tanem-site-engine-v2 и структуру templates/client.
Возьми ближайший эталон данных из examples/, но не копируй чужие тексты,
контакты, аналитику и изображения. Не создавай персональные HTML/CSS/JS-патчи.
Если публичного источника недостаточно, задай одним сообщением только вопросы,
без ответов на которые пришлось бы выдумывать факты.

Собери site.json, подготовь только клиентские WebP/AVIF-изображения,
проверь все ссылки и цены, запусти тестовую сборку, настрой GitHub Pages,
проверь desktop и mobile, затем верни ссылки на репозиторий, Actions и сайт.
Не меняй существующие production-репозитории и DNS без моего разрешения.
```

Для партии замените блок `Источник / Репозиторий / Домен / Специализация` таблицей клиентов. Каждый клиент всё равно должен получить отдельный репозиторий, отдельную сборку и отдельный отчёт проверки.
